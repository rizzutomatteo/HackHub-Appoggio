HackHub — Client demo

Client web (HTML + vanilla JS) che chiama le REST API di HackHub sullo stesso host.

Flusso end-to-end

Premi i bottoni in ordine (1 → 8). Ogni passo usa i dati creati dai passi precedenti (email, nomi). Le risposte JSON appaiono a destra.

1. Registra 2 utenti
2. Crea un hackathon
3. Crea un team
4. Iscrivi il team all'hackathon
5. Richiedi supporto (mentoring)
6. Proponi una call
7. Paga il montepremi
8. Extra

Stato demo (email/nomi generati): nessun dato ancora
